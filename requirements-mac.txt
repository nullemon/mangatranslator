# ── Mac accelerator stack (Apple Silicon M1/M2/M3/M4, and Intel Macs) ──
#
#   Install with:   ./setup_mac.command      (or: pip install -r requirements-mac.txt)
#
# There is no CUDA on a Mac, so nothing here is an "-gpu" build:
#   * torch's normal macOS wheels already include Metal (MPS) support, which
#     is what accelerates the balloon model, manga-ocr, LaMa and the upscaler
#     on Apple Silicon. The app switches to it automatically.
#   * onnxruntime (plain) is the right one — on macOS it ships the CoreML
#     execution provider, which runs the text-stroke model on the Apple
#     Neural Engine / GPU. onnxruntime-gpu does not exist for macOS.
#
# On an Intel Mac everything below still installs and works, just on CPU.
